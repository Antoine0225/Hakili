Version 1.0 — Logiciel Professionnel de Gestion Avicole Connecté

Nous vous remercions d'avoir choisi Hakili pour piloter, sécuriser et 
optimiser vos activités avicoles. Cet assistant va installer l'application 
"Hakili" sur votre ordinateur en quelques secondes.

-------------------------------------------------------------------------------
📌 CONSEILS AVANT DE COMMENCER L'INSTALLATION :
-------------------------------------------------------------------------------
1. FERMEZ VOS APPLICATIONS : Pour éviter tout conflit de mémoire Windows lors de 
   l'installation des bibliothèques de caisse et de l'interface, veuillez 
   fermer tous les autres programmes en cours d'exécution.

2. CONNEXION INTERNET ACTIVE : Ce logiciel fonctionne en synchronisation directe 
   avec nos serveurs cloud sécurisés. Assurez-vous que votre ordinateur dispose 
   d'une connexion internet active (WiFi ou câble) pour valider votre licence 
   d'accès dès le premier démarrage.

3. DROITS ADMINISTRATEUR : L'installation nécessite les privilèges d'Administrateur 
   Windows. Cela est indispensable pour permettre au système d'Auto-Update 
   d'appliquer automatiquement les futures mises à jour de sécurité de votre caisse 
   sans que vous n'ayez à réinstaller le logiciel manuelle.

-------------------------------------------------------------------------------
📦 CE QUI VA ÊTRE INSTALLÉ SUR VOTRE PC :
-------------------------------------------------------------------------------
- Le module de caisse professionnel pour enregistrer vos arrivages et vos ventes.
- Le calculateur de marge nette automatique connecté à la poche du Boss.
- L'accès illimité à l'Expert Virtuel IA Aviculture pour vos conseils vétérinaires.
- Le raccourci officiel Hakili directement sur votre bureau Windows.

Veuillez cliquer sur le bouton "Suivant" pour entamer la configuration de 
votre nouvel outil de travail.
